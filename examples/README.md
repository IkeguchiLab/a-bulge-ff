# System-specific examples

This directory contains system-specific PLUMED implementations of
gHBfix-18Ab.

- `6VA1/`: MAPT A-bulge system
- `2KOC/`: cUUCGg tetraloop system

The atom-type assignments and donor–acceptor pair lists in each example
depend on the atom numbering of the corresponding `step3_input.pdb` file
and should not be transferred directly between systems.
